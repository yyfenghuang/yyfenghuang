##  About Me

- I build software that lets machines speak.
- Currently building **Fortune Labs**, exploring hardware-software co-design, embedded platforms, and direct semantic communication.
- My work spans firmware, electronics, system architecture, and engineering validation.
- Interested in making complex physical systems more observable, testable, and reliable.
